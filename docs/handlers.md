# handlers description

## /users
- GET /users - get all users
- GET /users/<id> - get user by id
- PUT /users/<id> - change user by id

## /auth
- POST /auth/register - register new user
- POST /auth/login - login
- POST /auth/reset-password - reset password

## /covers
- GET /covers - get all categories/covers
- GET /covers/id - get cover by id
- POST /covers - create new cover
- PUT /covers/id - update cover by id

## /receipts
- GET /receipts - get all receipts
- GET /receipts/id - get receipt by id
- POST /receipts/id - create new receipt
